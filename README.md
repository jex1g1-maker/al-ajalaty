# Al Ajalaty (العجّاتي) 🚲⚙️

Al Ajalaty is a lightweight, all-in-one e-commerce web application dedicated to bicycles, accessories, and spare parts. Designed for cycling enthusiasts, the platform provides an easy and fast way to browse bike parts, view accessories, and place orders through a streamlined digital storefront.

---

## 🚀 Key Features
- **All-in-One Architecture:** Combines HTML, CSS, and JavaScript into a single, highly optimized file for ultra-fast loading and simple deployment.
- **Bicycle & Accessories Catalog:** Clean interface showcasing various bike models, essential gear, and replacement spare parts.
- **Firebase Integration:** Powered by Firebase for real-time inventory tracking, product management, and handling customer orders.
- **Fully Responsive:** Styled with custom CSS to ensure a seamless browsing and shopping experience across mobile and desktop devices.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Consolidated in a single file)
- **Backend & Database:** Firebase
